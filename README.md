# Arun Kumar — Portfolio

Single-page portfolio site (`index.html`). No build step needed — plain HTML/CSS/JS.

## 3. Deploy (pick one — all free)

### Vercel (recommended, fastest)
```bash
npm i -g vercel
cd portfolio
vercel --prod
```

### Netlify
```bash
npm i -g netlify-cli
cd portfolio
netlify deploy --prod
```
```
Then in the repo: Settings → Pages → Deploy from branch → `main` / `root`.
