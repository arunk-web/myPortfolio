04 · projects

Things I've built

askpdf.py
AskPDF — RAG Document Q&A
in progress

A RAG-powered system that lets users upload PDFs and query them through a conversational LLM interface, with answers grounded strictly in document content via real-time streaming. Documents run through a 5-stage async pipeline (parse → chunk → embed → index → search), handling PDFs up to 20MB and generating 768-dimensional embeddings for semantic vector search. PDF processing is offloaded to a decoupled Redis worker using a BRPOP blocking queue, so the API returns a 202 Accepted immediately while job status is tracked via Redis Hashes. Hallucination mitigation uses similarity thresholding (≥0.7 cutoff) to reject low-relevance context, with automated state cleanup to prevent orphan records in MongoDB during worker failures. Backend is built and working — currently wiring up the frontend.
